# APIDev.rules

APIDev.rules is a rule set for AI agents that design, review, and implement APIs.

The rules are distilled from [The API Book: 3rd Edition](https://github.com/twirl/The-API-Book) by Sergey Konstantinov and are organized as reusable Markdown source files. The project is intended to produce agent-ready guidance for general API development, REST APIs, and SDK design.

## Status

Early draft. The rule set is still being extracted, reviewed, and reorganized.
